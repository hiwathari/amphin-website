# amphin.agency: search, directory and AI visibility

No one can guarantee a #1 position on Google, Bing or in AI answers. Rankings depend on competition,
reviews, links from other sites and how long the domain has been live. What we can do is make the
site as easy as possible to find, understand and cite, and get Amphin listed everywhere people look.
This file lists what the site already does and what the team still needs to do.

Names of crawlers and directories below were correct as far as we know in October 2026. Check each
service's own help pages when you sign up, because they change.

## Already built into the site

- Clean addresses with the search phrase in them: `/uk/branding-agency-london`, `/in/seo-agency-kochi`,
  `/ae/social-media-marketing-agency-abu-dhabi`, `/uk/make-me-a-celebrity`.
- 195 local pages (9 service categories and their services × London, Kochi, Abu Dhabi), each with one H1,
  keyword H2s, office address and phone, local prices, FAQs and links to related pages.
- Structured data that Google, Bing and AI assistants read: Organization, LocalBusiness/ProfessionalService,
  Service, Offer (starting price), FAQPage, BreadcrumbList, BlogPosting (with author), VideoObject, CreativeWork.
- Five regional versions (/uk /eu /us /in /ae) linked with hreflang so each country sees its own currency.
- `sitemap.xml`, `robots.txt` (all search and AI crawlers allowed), and `llms.txt` (a plain-text summary
  for AI assistants listing what Amphin does and which pages to cite).
- Share cards (Open Graph and X/Twitter) on every page, fast pages, mobile layout, and descriptive image alt text.
- Studio → Settings → Analytics & search: paste the Google Search Console and Bing verification codes
  and the Google Analytics ID there; the site adds them automatically.

## Search engines: register and submit the sitemap (`https://www.amphin.agency/sitemap.xml`)

| Engine | Where | Notes |
|---|---|---|
| Google | Google Search Console | Verify with the code in Studio settings, submit the sitemap, request indexing for the home page and /make-me-a-celebrity. |
| Bing | Bing Webmaster Tools | Can import from Search Console. Bing's index also feeds Yahoo, DuckDuckGo, Ecosia and (we understand) parts of ChatGPT search and Microsoft Copilot. |

## AI assistants and answer engines

| Assistant | How it finds Amphin | What helps |
|---|---|---|
| ChatGPT (OpenAI) | OpenAI's crawlers and search partners, including Bing | Bing Webmaster Tools, llms.txt, FAQ pages, reviews on Clutch/Trustpilot |
| Claude (Anthropic) | Web search and Anthropic's crawler | Clear factual pages, llms.txt |
| Google Gemini & AI Overviews | Google's index | Search Console, structured data, FAQ answers |
| Microsoft Copilot | Bing | Bing Webmaster Tools, Bing Places |
| Perplexity | Its own crawler plus search partners | Being cited by directories and press |
| Meta AI, Apple Intelligence, You.com, Brave Leo | Their own crawlers and partners | Consistent listings and social profiles |

The single biggest factor for AI answers is being mentioned by other trusted sites: directory profiles,
reviews, press articles and guest posts. The site can't create those links itself; the team has to earn them.
